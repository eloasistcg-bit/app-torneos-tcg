# app-torneos-tcg

This repository is a Next.js 16 app using the App Router, TypeScript, Tailwind v4, and Supabase.
Do not remove or edit the `nextjs-agent-rules` block above; it is regenerated by `next dev`.

## Key areas
- `app/page.tsx` — main calendar UI reads `eventos` from Supabase.
- `app/Registro/page.tsx` — client registration form posts to `/api/registro`.
- `src/lib/supabase.js` — Supabase client configured from `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY`.
- `app/layout.tsx` and `app/globals.css` — global app shell and styling.
- `public/` — static images and assets used by the site.

## Commands
- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run lint`

## Environment
- Requires `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_ANON_KEY` in `.env.local`.
- `src/lib/supabase.js` throws if these env vars are missing.

## Guidance for agents
- Prefer working in `app/` and `src/lib` rather than introducing a new server framework.
- Confirm the `/api/registro` route exists before depending on it, because `app/Registro/page.tsx` fetches from that endpoint.
- Preserve the `@/*` import alias configured in `tsconfig.json`.
- The app uses client components for interactive pages; respect `use client` boundaries.
- Do not assume database tables exist; `app/page.tsx` reads from a `eventos` table in Supabase.
